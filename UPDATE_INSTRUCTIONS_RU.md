# Обновление до 2.1

Распакуй содержимое в корень существующего репозитория с заменой указанных файлов. Архив содержит только изменённые и новые файлы; исправленный ранее `.github/workflows/build.yml` не заменяется. Если есть собственные изменения в этих файлах, сначала сохрани их или выполни слияние вручную.

Проверь `git diff`, затем `git add .` и `git commit -m "feat: detect unregistered local HOI4 mods"`, `git push`. Дождись CI на Windows. После тестирования можно выпустить тег `v2.1.0-beta.1`.

Запусти новый EXE, примени настройки и перезапусти Проводник. Автоопределение применяется только к прямым дочерним каталогам стандартного локального каталога HoI4 mod. Steam Workshop и внешние каталоги добавляются вручную. В совместимом режиме автоматический переход доступен с фона папки.
